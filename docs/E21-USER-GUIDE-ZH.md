# The Minish Cap 3DS 中文版 E21 使用说明

适用文件：

- `tmc-3ds-cn-angel-sp4-v1.3-E21.cia`
- `tmc-3ds-v1.3-E21.3dsx`

## 首次启动：先开启声音（重要）

首次游玩前，请先在 3DS 上完成一次 DSP 音频初始化：

1. 同时按住 **L + 十字键下 + SELECT**，打开 Luma3DS Rosalina 菜单。
2. 进入：

   ```text
   Miscellaneous options
   ```

3. 选择：

   ```text
   Dump DSP firmware
   ```

4. 等待屏幕提示完成，按 B 返回并关闭 Rosalina 菜单。
5. 退出并重新启动游戏，此后音乐和音效会正常播放。

这项操作通常只需执行一次。日后系统环境变化或声音再次消失时，可重新执行以上步骤。

## 1. 安装与首次启动

### CIA 方式

1. 把 CIA 文件复制到 3DS 的 SD 卡。
2. 打开 FBI，找到 CIA 文件并安装。
3. 在 SD 卡建立目录：

   ```text
   sdmc:/3ds/The Minish Cap 3DS/
   ```

4. 把自己准备的美版或欧版 `.gba` 游戏文件放进该目录。文件名可自定，扩展名保持 `.gba`。
5. 从 3DS 主菜单启动游戏。

### 3DSX 方式

1. 把 3DSX 文件复制到 SD 卡的 Homebrew 应用目录。
2. 同样建立：

   ```text
   sdmc:/3ds/The Minish Cap 3DS/
   ```

3. 把 `.gba` 游戏文件放进该目录。
4. 通过 Homebrew Launcher 启动 3DSX。

欧版与美版均可自动识别。欧版是本项目主要测试版本。

## 2. 下屏总览

下屏底部有四个入口：

| 入口 | 作用 |
| --- | --- |
| 任务 | 查看剑、心之碎片、剑技、元素、重要物品等收集状态 |
| 地图 | 查看大地图、地区地图或迷宫楼层图 |
| 道具 | 查看已获得道具，并给 A/B 键快速配装 |
| 齿轮按钮 | 进入画面、游戏、开发和随机模式设置 |

再次点击当前已打开的“任务”或“道具”标签，会直接回到地图。

右侧状态栏会根据当前进度显示生命、卢比、迷宫钥匙，以及 A/B 键当前装备。

## 3. 地图功能

### 世界地图

- 在室外时，地图会显示林克当前所在位置。
- 进入房屋或洞穴后，会保留最近一次室外位置，方便辨认出口区域。
- 点击地图中的区域，可打开该区域的详细地图。
- 点击“返回”或再次点击地图，可回到上一级。

### 放大与缩小

- 当前为全地图时，按钮显示“放大”，点击后进入跟随林克的近景地图。
- 当前为近景地图时，按钮显示“缩小”，点击后显示整个海拉鲁。

### 迷宫地图

- 进入迷宫后，下屏自动显示迷宫名称、当前楼层和已经探索的房间。
- 点击左侧 `1F`、`B1`、`B2` 等楼层牌，可预览其他楼层。
- 点击林克当前所在楼层，可立即回到实时楼层。
- 开启“楼层自动返回”后，预览其他楼层约 6 秒会自动回到当前楼层。

## 4. 道具功能

下屏道具页支持触摸配装：

- 轻点一个已获得的道具：装备到 **A 键**。
- 长按一个已获得的道具：装备到 **B 键**。
- 也可先点击右侧 A 或 B 装备圆环，再点击目标道具。
- 再次点击已经选中的圆环，可取消本次配装选择。

右侧 A/B 圆环会即时显示当前装备，道具数量也会同步显示。

## 5. 任务功能

任务页集中显示冒险进度，包括：

- 当前剑与强化进度
- 心之碎片
- 已学习的剑技数量
- 四大元素
- 重要剧情道具
- 贝壳、奖牌与模型收集
- 攀爬戒指、力量手镯、脚蹼等能力装备

点击融合石袋，可打开融合石列表；点击剑技图标，可打开已学习剑技列表。点击“返回”回到任务总览。

## 6. 设置功能

点击右下角齿轮进入设置。设置分为四组。

### 画面

| 项目 | 说明 |
| --- | --- |
| 画面比例 | 在“宽屏 / 原始 / 拉伸”之间切换 |
| 显示样式 | 在“柔化 / 双线性 / 点对点”之间切换 |
| 上屏状态栏 | 显示或隐藏上屏生命与道具状态栏 |
| 色彩校正 | 切换更接近 GBA 色彩的显示处理 |
| 面板背景 | 切换图案、米白、深色、暗色、石色、灰蓝、藏蓝主题 |
| 画面重置 | 恢复默认画面比例、双线性显示，并关闭色彩校正 |

New 3DS 使用“宽屏 + 点对点”组合时，会启用实验性的完整视野显示。

### 游戏

| 项目 | 说明 |
| --- | --- |
| 加速倍数 | 在 X2、X3、X4、X5 之间循环；使用 C-Stick 触发加速 |
| 风之印标记 | 显示或隐藏世界地图上的风之印位置 |
| 楼层自动返回 | 预览其他迷宫楼层约 6 秒后回到当前楼层 |
| 主音量 | 在 0、25、50、75、100 之间循环 |
| 自动保存 | 开关定时自动保存功能 |
| 按住推进文字 | 开启后，按住确认键可连续推进对话文字 |

### 开发

| 项目 | 说明 |
| --- | --- |
| 内存转储 | 保存上下屏截图、运行状态、性能数据和调试文件 |
| 读取状态 | 读取最新一次调试转储中的游戏状态 |
| 显示帧率 | 在上屏显示实时帧率 |
| 信息层 | 查看版本、主机型号、实时/平均帧率、核心负载、屏幕、区域和房间编号 |

调试转储会保存到：

```text
sdmc:/3ds/The Minish Cap 3DS/dumps/
```

游戏中也可按 **L + R + A** 快速建立调试转储。遇到崩溃、黑屏或图形问题时，可把最新的 `dump-*` 文件夹打包后发给项目维护者。

“读取状态”属于复现问题用的调试功能：它会用最新调试状态替换当前运行状态，操作前请先保存游戏进度。不同 ROM 区域或损坏的状态文件会被自动拦截。

### 随机模式

- 点击开关后会出现确认页面。
- 模式切换会清理当前存档、自动存档、即时状态和随机数据，然后自动重启。
- ROM 文件会保留。
- 开启随机模式后请新建游戏。
